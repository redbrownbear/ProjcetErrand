# 기획 시안 v33 → 앱 디자인 적용

출처: `겸사겸사_v33.html` (단일 HTML 시안). 오른쪽 디자인 노트(`aside.notes`)는 빼고
폰 화면(`#app`)만 기준으로 삼았다. 기능·데이터 흐름은 그대로 두고 화면 구성과 스타일만 옮겼다.

## 1. 토큰

| 토큰 | 값 | 시안 |
| --- | --- | --- |
| `ink` / `ink2` | `#191F28` / `#333D4B` | `--ink` / `--ink2` |
| `sub` / `faint` | `#6B7684` / `#B0B8C1` | `--sub` / `--faint` |
| `line` | `#EEF0F3` | `--line` |
| `page` / `soft2` | `#F2F4F6` / `#E8EBEE` | `--soft` / `--soft2` |
| `yellow` | `#FFCD1F` | `--y` |
| `green` · `red` · `blue` · `purple` | `#18A874` · `#F04452` · `#3A7BF5` · `#7461F0` | `--g --r --b --v` |

화면 바탕은 옅은 회색(`page`), 내용은 그 위의 **흰 카드**(모서리 18, 좌우 10px)다.
예전 시안의 색 이름(`inkSoft`, `btnPrimary`, `goalMint…` 등)은 다른 화면이 그대로 쓰고 있어
이름은 남기고 값만 v33 팔레트로 바꿨다.

서체: 시안은 Noto Sans KR(800·900 사용)이지만 앱은 번들한 Pretendard(400~700)를 유지했다.
800·900은 Bold(700)로 그려진다.

## 2. 하단 메뉴 · 상단 헤더

| 개편 전 | 개편 후 |
| --- | --- |
| 홈 · 부업 · (부탁하기) · 채팅 · 내 정보 | 홈 · **미션·공구** · **해외** · 채팅 · **마이** |

- 가운데 '부탁하기' 버튼은 없어졌다. 부탁은 홈 겸이 카드의 버튼과 상단 연필 버튼에서 쓴다.
- 상단 헤더는 셸(`home_shell.dart`)이 그린다. 홈은 동네 이름, 다른 탭은 탭 제목.
  오른쪽은 검색(홈만) · 부탁하기 · 알림. 진행 중인 부탁이 있으면 알림에 빨간 점.
- 앱을 열면 시작 화면(겸이 + 한 줄 소개)이 1.6초 보이고, 누르면 바로 넘어간다.

## 3. 화면별

| 화면 | 파일 | 시안 |
| --- | --- | --- |
| 홈 (부탁하기 / 돈벌기) | `features/errand/screens/home_content.dart` | `#homeRoot` |
| 미션·공구 (미션 / 공동구매) | `features/benefits/screens/side_job_view.dart` | `#sideRoot` |
| 해외 (부탁하기 / 돈벌기) | `features/errand/screens/overseas_tab.dart` (신규) | `#osRoot` |

| 마이 | `features/profile/screens/me_view.dart` | `#myRoot` |

공통 부품: `core/widgets/mascot.dart`(겸이 · 겸이 카드), `core/widgets/surface.dart`
(섹션 카드 · 전환 토글 · 밑줄 탭 · 배지 · 예시 넘김 등). 부탁 한 줄(`TaskCard`)과
미션 한 줄(`MissionTile`)은 시안의 `.row`로 바꿨다.

겸이는 시안의 SVG를 패키지 없이 `CustomPainter`로 옮겼다. 위아래로 천천히 떠 있고,
기기에서 애니메이션을 끄면 멈춘다.

## 4. 시안과 다르게 둔 것

지어낸 숫자를 사실처럼 보여 주지 않는다는 기존 원칙 때문에 아래는 실제 데이터로 바꾸거나 뺐다.

- **겸이 카드의 한 줄**(“성심당 빵 사다주기 완료 · 14분 전”): 실제 올라온 부탁에서 뽑는다. 예시 데이터면 '예시'라고 붙인다.
- **응모권 · 럭키드로우**(헤더의 '12장', 미션 탭 배너): 앱에 없는 기능이라 옮기지 않았다.
- **이번 주 출국 이웃 보드**(해외): 출국 일정 데이터가 없어 옮기지 않았다.
- **가격변동 예비금 30%**(해외): 앱 정책이 아니라서 '물건값은 영수증 정산, 부탁 비용 2만원부터'로 적었다.
- **마이 지갑의 '모은 돈'**: 시안은 원+포인트를 더하지만, 겸사페이(원)와 포인트(P)는 섞지 않는다는 원칙대로 따로 적었다.
- **'가는 김에' 게시판**: 같은 기능이 없어 '같이해요' 글을 보여 준다.
- **우리 동네 제휴 가게 · 혜택**: 회원 전용가(`member_deals.dart`) 데이터를 쓴다.

## 5. 홈에서 옮긴 것

v9 홈에 있던 출석 달력 · 겸사겸사 소식 · 지갑 요약 · 가볍게 모으기는 v33 홈에 없다.

- 출석 → 마이 › 지갑 카드 '내역·출석'
- 가볍게 모으기(매일 미션) → 홈 바로가기 '전체' 시트, 미션·공구 › 매일의 혜택
- 지도 · 반경 · 정렬 · 종류 · 30분 조건 → 돈벌기 '지금 내 주변 부탁' 카드의 조건 줄
