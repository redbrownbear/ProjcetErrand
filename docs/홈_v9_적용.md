# 기획 시안 v9 → 홈 적용 기록

출처: `gyumsa-home-v9` (React/Vite 시안, `src/Explore.jsx`·`src/HomeCompact.jsx`)

기획자 최신본인 v9의 홈 구조를 Flutter 홈(`lib/features/errand/screens/home_content.dart`)에
그대로 옮기면서, 여러 곳에 흩어져 있던 같은 기능의 진입점을 하나로 줄인 기록이다.

## 1. 홈 구성 (v9 Explore 순서)

| 순서 | 영역 | 구현 |

## 2. 중복 제거 결과

개편 전 홈은 섹션이 22개였고 같은 기능 진입점이 여러 곳에 있었다.

| 기능 | 개편 전 | 개편 후 |
| --- | --- | --- |
| 걷기 | 홈 3곳 + 혜택 뷰 | 숏컷 '전체' 펼침 1곳 |
| 제휴 미션 | 홈 2곳 + 혜택 뷰 + 부업 허브 | 숏컷 '미션' → 오늘 벌기 허브 1곳 |
| 공동구매 | 홈 2곳 + 혜택 뷰 | 숏컷 '공동구매' → 생활비 아끼기 허브 1곳 |
| 단기알바 | (없음) / MOU 작업의 '일급·일당' | '단기알바'로 이름 통일, 주요 서비스 + 탭 |

홈에서 없어진 목록 섹션(30분 안에 끝나요 · 사례비 높은 부탁 · 지금 급해요 ·
가는 길에 · 처음이라면)은 지우지 않고 **탐색 영역의 조건**으로 흡수했다.
반경·정렬·30분 필터를 바꾸면 같은 결과를 볼 수 있고, `부탁 전체` 숏컷의
목록 화면에서도 동일한 정렬을 제공한다.

## 3. MOU 구조와의 관계

MOU 가이드 §15의 2축(오늘 벌기 / 생활비 아끼기)은 **없애지 않고 v9 진입점 뒤로** 옮겼다.
홈의 1차 메뉴는 v9을 따르고, 두 허브는 숏컷의 목적지로만 존재한다.
자세한 내용은 [제휴전략_앱적용.md](제휴전략_앱적용.md) 참고.

## 4. v9에서 고친 것

- v9의 `parseInt(m.time)`은 `'1~2시간'`을 `1`로 읽어 1~2시간짜리 좌담회가
  '가볍게 모으기'에 올라온다. Flutter 쪽은 시간 단위를 구분해(`_LightMissions._minutes`)
  30분 이하만 노출한다.
- v9의 지도/목록은 같은 화면에서 전환하지만, 여기서는 같은 조건으로 필터된 목록을
  그대로 지도 화면에 넘긴다. 결과가 일치한다는 점은 동일하다.

## 5. v9에 있으나 옮기지 않은 것

- 로고 이미지(`brand.png`) 표시 — 현재 앱 헤더 디자인과 맞지 않아 보류
- 목표 금액의 기기 간 동기화 — v9도 브라우저 로컬이며, 앱도 `LocalStore`(이 기기)에만 보관
