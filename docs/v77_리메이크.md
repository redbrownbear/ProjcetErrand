# 기획 시안 `겸사겸사_v77.html` → 앱 리메이크 기록

출처: `겸사겸사_v77.html` (기획자 최신 프런트 시안, 디자인 노트 v42~v44-4)

v77은 v9/`gyumsa-refined` 위에 덧칠한 게 아니라 **구조를 다시 짠 시안**이다.
그래서 이번에는 색만 바꾸지 않고 셸(머리줄 · 하단 메뉴)과 탭 구성을 시안대로 다시 만들었다.

예전 이름은 그대로 두고 값만 바꿨다 — 부탁 상세·지갑처럼 다시 만들지 않은 화면도 같은 색으로 맞춰진다.
모서리: 히어로·LIVE 보드 20 · 흰 카드 18 · 버튼/입력 14~15.

화면은 회색 바탕 위에 좌우 10px 여백의 흰 카드를 8px 간격으로 쌓는다.
이 규칙은 `lib/core/widgets/kit.dart`(`Sec` · `Seg` · `BigTabs` · `UnderTabs` · `ChipRow` · `BigButton` …)에 모았다.

서체는 시안이 Noto Sans KR을 CDN으로 부르지만, 앱은 오프라인에서도 같은 모양이 나와야 해서
기존에 번들한 Pretendard를 그대로 쓴다.

캐릭터 **겸이**는 시안의 SVG(`.gm`)를 `CustomPainter`로 옮겼다 (`gyeom_mascot.dart`). 패키지 추가 없음.

## 2. 셸

| | 이전 | v77 |
| --- | --- | --- |
| 하단 메뉴 | 홈 · 부업 · (부탁하기) · 채팅 · 내 정보 | **홈 · 마켓 · 커뮤니티 · 채팅 · 마이** |
| 머리줄 | 화면마다 다름 | 동네(또는 탭 이름) · **응모권 n장** · **글쓰기** · 알림 |

- **글쓰기**는 한 곳에서 고른다 — 가는 김에 · 제안하기 · 부탁하기 · 해외 부탁하기 · 중고 판매·나눔 · 커뮤니티 글쓰기.
- 탭은 `IndexedStack`이라 탭을 오가도 스크롤·필터가 남는다.

## 3. 홈

맨 위 **국내 / 해외** 스위치. 해외는 파란색이다.

- 국내 · 부탁하기: 히어로(겸이 + 럭키드로우 말풍선) → LIVE 제안 보드 → 여행 다트 → 이런 것도 부탁해도 돼요 →
  가게 광고 배너 → 자주 하는 부탁 10칸 → 숏컷 → 우리 동네 제휴 가게 → 가는 김에
- 국내 · 돈벌기: 히어로 → 이번 달 내가 번 금액 → 이거 하나 하고 갈래요? → 지금 내 주변 부탁(동네 부탁 / 단기알바, 거리·정렬) →
  배너 → LIVE 보드 → 가는 김에 → 우리 동네 혜택 → 해외 부탁 가로 목록 → 미션·공구로 더 벌기
- 해외 · 부탁하기 / 돈벌기 / **현지 이웃**

### 응모권 규칙 (`TicketRules`)

| 행동 | 응모권 | |
| --- | --- | --- |
| 출석 체크 | 1 | 하루 한 번 |
| 부탁 해주기 완료 / 해외 사다주기 완료 | 3 | 거래가 '완료'로 바뀔 때 |
| 내 부탁 완료 확인 | 2 | |
| 가게 방문 인증 | 2 | 방문 미션 완료 |
| 설문·앱 체험 완료 | 1 | 그 밖의 미션 |
| 커뮤니티 글·답글 | 1 | |
| 첫 부탁 올리기 | 5 | 계정당 한 번 |
| 푸시 동의 / 프로필 사진 | 10 / 3 | 계정당 한 번 (화면만 있고 아직 연결 전) |

응모권은 포인트(P)·겸사페이(원)와 섞지 않는다. 구매·환전·양도 불가.
**처음 시작하면 0장**이다 — 시안의 '12장'은 예시 숫자라 지어내지 않았다.
추첨·발표는 서버가 붙어야 해서, 지금은 응모권을 응모함으로 옮기는 데까지만 한다.

## 5. 보관

새 기능의 기록(내 제안 · 구매 요청 · 글 · 답글 · 좋아요 · 가는 김에 · 중고 · 응모권)은
`NeighborStore`(`lib/app/neighbor_store.dart`)가 들고 **이 기기에만** 보관한다(`LocalStore`).
부탁·거래·포인트·겸사페이는 원래대로 셸이 들고 있고 로그인하면 서버와 맞춘다.
참여 행동(제안·구매 요청·글쓰기)은 기존처럼 로그인 뒤로 미룬다.

## 6. 정리한 것

v9 홈과 부업 탭은 v77 홈·마켓으로 완전히 대체되어 지웠다.
`home_content.dart` · `side_job_view.dart` · `benefits_view.dart` · `create_choice_screen.dart` ·
`local_errand_hub_screen.dart` · `search_screen.dart` · `news_detail_screen.dart` (git 기록에 남아 있다)

매일 미션·퀴즈(제휴 API 연동분)는 **마켓 › 미션 › 가볍게 모으기**로 옮겨 그대로 쓴다.

## 7. 체험 데이터

LIVE 보드 제안 · 커뮤니티 글 · 중고/나눔 · 현지 이웃 · 제휴 가게 · 공동구매는 시안의 예시를 옮긴 **체험용 샘플**이다.
제휴가 체결된 것이 아니며, 광고 자리에는 '광고' 표시를 붙였다. 제안 날짜는 실행한 날 기준으로 계산한다.
