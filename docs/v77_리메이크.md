# 기획 시안 `겸사겸사_v77.html` → 앱 리메이크 기록

출처: `겸사겸사_v77.html` (기획자 최신 프런트 시안, 디자인 노트 v42~v44-4)

v77은 v33과 같은 계열의 더 새 시안이다. 앱은 v33 적용 + 전체 리팩토링(2026-10-02, jyh) 위에
**v77에서 달라진 것만** 얹었다. 홈·해외·미션·마이의 뼈대는 v33 리팩토링 결과(`HomeContent`·`OverseasTab`·
`SideJobView`·`MeView`·`surface.dart` 부품)를 그대로 쓰고, 새 기능만 따로 둔다.

## 1. 디자인 토큰 · 부품

색·모서리·서체는 v33 적용분(`colors.dart` · `app_theme.dart`)을 그대로 쓴다. v33과 v77은 같은 팔레트다
(먹색 `#191F28` · 바탕 `#F2F4F6` · 노랑 `#FFCD1F` · 해외 파랑 `#3A7BF5`). v77에서 새로 필요한 것만 더했다.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `outline` | = `soft2` | 버튼·입력창 1px 테두리 |
| `greenDeep` | `#0B7A51` | '중고' · '현지 거주 확인' 배지 |
| `purpleLine` | `#D9D2FF` | LIVE 보드의 AD 줄 테두리 |
| `liveBg` · `liveLine` | `yellowSoft` · `#F3E2A3` | LIVE 보드 · 오늘의 질문 |
| `tabIdle` | `#B5B7BF` | 국내/해외 큰 탭의 꺼진 글자 |
| `AppType.bigTab` | 23 / w700 | 국내/해외 큰 탭 |

카드·섹션 제목·세그먼트·배지는 팀 공용 `surface.dart`(`SecCard` · `SecHead` · `SegToggle` · `UnderlineTabs` ·
`StatusBadge` · `TextLink` · `SoftButton`)를 쓴다. 그 밖에 v77 화면에만 필요한 것
(시트 뼈대 · 큰 버튼 · 칩 줄 · 응모권 칩 등)은 `core/widgets/kit.dart`에 있다.

겸이는 v33의 `Gyeomi`, 겸이 카드는 v33의 `HeroCard`를 쓴다. v77의 럭키드로우 말풍선은
`HeroCard(bubble: LuckyBubble(...))`로 붙인다.

## 2. 셸

| | v33 | v77 |
| --- | --- | --- |
| 하단 메뉴 | 홈 · 미션·공구 · 해외 · 채팅 · 마이 | **홈 · 마켓 · 커뮤니티 · 채팅 · 마이** |
| 해외 | 하단 탭 | 홈 맨 위 **국내 / 해외** 전환 (`OverseasTab`을 홈 안에서) |
| 헤더 오른쪽 | 검색 · 부탁하기 · 알림 | **응모권 n장** · **글쓰기** · 알림 시트 (검색은 홈 '전체') |

- **글쓰기**는 한 곳에서 고른다 — 가는 김에 · 제안하기 · 부탁하기 · 해외 부탁하기 · 중고 판매·나눔 · 커뮤니티 글쓰기.
  단기알바 모집은 홈 바로가기 '전체'에 있다.
- `ShellTab.side`는 이름은 그대로 두고 '마켓'이 됐다 (`SideJobView` 4칸).

## 3. 홈 · 해외 · 마켓 · 마이에 더한 것

v33 화면에 v77 조각만 끼웠다.

- 홈 부탁하기·돈벌기: 겸이 말풍선(럭키드로우) · LIVE 제안 보드 + 여행 도구(`LiveSection`) · '가는 김에' 글(`TripFeedSection`,
  예전 같이해요 대신) · 바로가기 '전체'에 검색·단기알바 모집·중고장터·럭키드로우·세계 제안 지도
- 해외(`OverseasTab`): 부탁하기 · 돈벌기 · **현지 이웃** 세 칸, 두 칸 모두 해외 LIVE 보드 + 세계 지도·다트
- 마켓(`SideJobView`): 럭키드로우 띠 · 미션 · 공동구매 · **중고장터 · 나눔**(+ 글쓰기 버튼)
- 마이(`MeView`): 지갑 아래 **내 응모권** 카드, 나의 활동 › 내 제안 · 구매 요청
- 커뮤니티 · 채팅: v77 화면

## 4. 새 기능

| 기능 | 위치 | 비고 |
| --- | --- | --- |
| **제안하기** | `features/proposal` | 가는 이웃이 먼저 올리고 원하는 이웃이 '저 구매할래요!'. 국내는 다른 지역 이동만. 정원 1~15명 또는 제한 없음. 영수증 기준 가격 고지 확인 필수 |
| LIVE 보드 | `proposal/widgets/live_board.dart` | 오늘·내일만 태그, 나머지 날짜는 작은 글씨. 1자리 남으면 빨강, 마감은 흐리게 |
| 제안 상세 | `proposal_sheet.dart` | 함께 요청한 이웃(공개 노랑/비공개 회색) · 그 지역 이웃 이야기 · 요청 뒤 '후기 남기기'(제목·지역 채워짐) |
| 세계 제안 지도 | `world_map_screen.dart` | 나라별 제안·요청 수, 나라 시트에 이웃 이야기 |
| 여행 어디 갈까? | `trip/widgets/dart_sheet.dart` | 다트 → 당첨 지역 이야기로 |
| **럭키드로우 · 응모권** | `features/lucky` | 아래 표 |
| 가는 김에 | `features/trip` | "내일 오사카 가요" / "오늘 성수 가시는 분?" |
| 커뮤니티 | `community/screens/community_view.dart` | 국내(우리 동네 · 여행) / 해외. 오늘의 질문, 피드 사이에 제안 카드가 섞임 |
| 중고장터 · 나눔 | `market/` | 다른 동네 물건은 '전달 부탁하기' → 돈벌기 목록에 '중고'로 (`AppSession.addDelivery`) |
| 현지 이웃 | `overseas/widgets/local_neighbors.dart` | 현지에서 직접 만나서 하는 일만 (택배·배송 없음) |

### 응모권 규칙 (`TicketRules`)

| 행동 | 응모권 | |
| --- | --- | --- |
| 출석 체크 | 1 | 하루 한 번 |
| 부탁 해주기 완료 / 해외 사다주기 완료 | 3 | 거래가 '완료'로 바뀔 때 |
| 내 부탁 완료 확인 | 2 | |
| 가게 방문 인증 | 2 | 방문 미션 완료 |
| 설문·앱 체험 완료 | 1 | 그 밖의 미션 |
| 커뮤니티 글·답글 | 1 | |
| 첫 부탁 올리기 | 5 | 계정당 한 번 |
| 푸시 동의 / 프로필 사진 | 10 / 3 | 계정당 한 번 (화면만 있고 아직 연결 전) |

부탁·미션·출석에서 받는 응모권은 `AppSession.onTicket`이 알려 주고 셸이 응모권 지갑에 쌓는다.
응모권은 포인트(P)·겸사페이(원)와 섞지 않는다. 구매·환전·양도 불가.
**처음 시작하면 0장**이다 — 시안의 '12장'은 예시 숫자라 지어내지 않았다.
추첨·발표는 서버가 붙어야 해서, 지금은 응모권을 응모함으로 옮기는 데까지만 한다.

## 5. 보관

새 기능의 기록(내 제안 · 구매 요청 · 글 · 답글 · 좋아요 · 가는 김에 · 중고 · 응모권)은
`NeighborStore`(`lib/app/neighbor_store.dart`)가 들고 **이 기기에만** 보관한다(`LocalStore`).
부탁·거래·포인트·겸사페이는 원래대로 셸이 들고 있고 로그인하면 서버와 맞춘다.
참여 행동(제안·구매 요청·글쓰기)은 기존처럼 로그인 뒤로 미룬다.

## 6. 옮기지 않은 것

- **이번 주 출국 이웃 보드** — 실제 출국 일정 데이터가 없어 지어낸 인원수를 보여 줘야 한다 (WORKLOG › 보류 › 아이디어)
- **예비금 30%** — 앱에 없는 정책
- 커뮤니티의 '이웃 312명' 같은 인원수 · 겸이 카드의 가짜 완료 소식 — 셀 근거가 없어 뺐다

## 7. 체험 데이터

LIVE 보드 제안 · 커뮤니티 글 · 중고/나눔 · 현지 이웃은 시안의 예시를 옮긴 **체험용 샘플**이다.
LIVE 보드 아래와 현지 이웃 탭에 '체험용 예시'라고 적어 둔다. 제휴가 체결된 것이 아니며, 광고 자리에는 '광고' 표시를 붙였다.
제안 날짜는 실행한 날 기준으로 계산한다.
