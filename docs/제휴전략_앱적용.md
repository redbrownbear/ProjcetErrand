## 2. 문구를 바꿀 때 주의할 점

- 규제 고지는 화면에 직접 쓰지 말고 `Disclosures`에 추가·수정한다. 제휴사 준법부서가 승인한
  문구로 교체될 때 파일 하나만 고치면 되게 하기 위함이다.
- 회원 전용가는 `basePrice`와 `baseSource`를 반드시 함께 채운다. 출처 없는 기준가는 표시하지 않는다.
  '최저가'라는 표현은 쓰지 않는다. (§10)
- 임상시험은 '임상 알바'가 아니라 '임상시험 참여정보', '연구 참여 기회'로 쓴다. (§5)
- 단기알바 공고는 `source`(직접 제휴 / 공고 연동)를 화면에 그대로 노출한다. 직업소개·파견 여부의
  법적 성격이 달라지므로 출처를 흐리지 않는다. (§11)

## 3. 아직 반영하지 않은 것 (백로그)

앱 화면이 아니라 서버·운영·영업 영역이라 이번에 코드로 옮기지 않았다.

| §7 | 기업 심부름 수행자 등급제 (완료 횟수·평점 기준, 금지 품목, 완료 증빙, 기업별 월 한도) | 수행자 등급·기업 계정 모델, 서버 |
